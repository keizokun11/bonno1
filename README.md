# 煩悩オークション flat版

GitHubのスマホ画面でフォルダごとアップロードできない場合のために、ルート直下のファイルだけで動くMVP版です。

## GitHubに入れるファイル

以下3つだけをリポジトリ直下にアップロードしてください。

- index.html
- vercel.json
- README.md

ZIPファイルそのものはアップロードしないでください。

## 画面URL

Vercelで公開後、以下のURLを開いてください。

- `/submit` 参加者投稿画面
- `/admin` 運営画面
- `/screen` スクリーン表示画面

## 注意

この版はまず公開確認用です。データはブラウザのlocalStorageに保存されます。
本番で別端末から投稿を集めるには、次にSupabase接続版に進んでください。
